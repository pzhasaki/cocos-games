## 2. Software Function Summary

Rollvive is a mobile casual survival roguelite game set on the alien planet Hexa-9. The player controls a profession-based hero, uses floating energy blades to cut through escalating monster waves, and builds a different combat style in each run through randomized hex enhancement drafts. Enhancements cover damage, blade behavior, defense, luck, economy and high-risk rewards, while every fifth wave introduces a boss encounter. The game focuses on short-session survival, readable mobile combat, and quick strategic choices between waves.

## 7. User Manual Draft

### Start Game

Open the game and tap Start. The default profession is Blade Adept. Future versions can expose profession selection before starting.

### Battle

The player survives alien waves. Attack, shield and ultimate actions are triggered by the input adapter. The player has HP and energy. When energy is full, the ultimate damages all active enemies.

### Hex Draft

After each cleared wave, the game shows a hex enhancement draft. The player chooses one upgrade to strengthen the current run. Gold can be spent to reroll the draft. Luck improves the chance of higher-color upgrades.

### Boss

Every fifth wave is a boss wave. Bosses have higher HP, stronger damage and larger rewards.

### Result

When the player dies or clears the target wave, the result panel shows reached wave, time, kills and damage.
